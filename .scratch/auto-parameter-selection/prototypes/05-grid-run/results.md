# Exploratory grid run: results

Facts only, for [Eligibility constraints and selection defaults](../../issues/06-eligibility-and-selection-defaults.md). No default is chosen here. Produced by [grid_run.py](grid_run.py) and [report.py](report.py) for [Exploratory grid run on the current Build](../../issues/05-exploratory-grid-run.md); every pair's numbers are in [pairs.csv](pairs.csv).

Neighbour Agreement appears here only as a distribution. Its per-pair values, which show which pair a set of constraints would select, are kept apart in [neighbour-agreement-by-pair.md](neighbour-agreement-by-pair.md), to be opened only after ticket 06 has fixed its defaults.

## Setup

- Build `20261008T221504Z-7a23ae9f`, all five Top-100 Datasets. Fixed settings: Genre Tags and the defining tag hidden, Minimum Months 0, Clustering Weight Lift, Leiden (`RBConfigurationVertexPartition`, `n_iterations=-1`).
- Parameter Grid: 3 ≤ g ≤ 20, 2 ≤ s ≤ 12, s ≤ g: 153 pairs per dataset, 765 in all.
- Procedure exactly as [Resolution-selection rules](../../issues/03-resolution-selection-rules.md): 56 γ (0.25 to 3.00, step 0.05) × 10 scan seeds = 560 Leiden runs per pair; dedup over all tags; CHAMP on [0.25, 3.00] with rtol 1e-12; γ̂ once per Admissible Partition with the four guards; minimum 3 Multi-Tag Clusters after stability; widest domain, ties to the lower midpoint.
- Scan seeds: `derive_seeds(20261003, stream=3, 10, exclude=replicate ∪ noise seeds)` = `[1558840077, 1805315920, 847274496, 1884995815, 744723460, 1847733752, 1737169755, 390569978, 1070228461, 1004727624]`. Stream 3 is this script's assumption; no ticket has fixed the stream number.
- Metrics exactly as [Per-pair metric definitions](../../issues/04-pair-metric-definitions.md). Seed-Noise Floor: `noise_seeds(20261003, 10, 20)` at the exact, unrounded Selected Resolution.
- The script calls `leidenalg.find_partition` on an igraph built once per pair rather than going through `cluster.detect` per run. On 9 (γ, seed) runs of one graph the memberships were identical to `detect`'s.
- Machine: 12 logical cores, Windows 11, Python 3.14.8, leidenalg 0.12.0, igraph 1.0.0, multiprocess 0.70.19.

## Headline facts

- 764 of 765 pairs have a Selected Partition. None has a clipped domain or is `not_representable`.
- The largest connected component holds every non-isolated tag in all 765 pairs (LCC share min 1.000). 632 of 765 pairs have no isolated tag.
- Information Retention runs from 0.407 to 0.928.
- 196 Selected Partitions have exactly 3 Multi-Tag Clusters, the minimum; 52 were found by only 1 of the 560 scan runs.
- Every pair with a Selected Partition has at least 2 comparable neighbours. Only the four neighbours of rpg g=18 s=4 (`too_few_multi_tag_clusters`, the one pair without a Selected Partition) have a missing neighbour.
- Wall-clock for all 765 pairs: 761 s serial, 95 s on 12 workers; 94–95% of the time is the Leiden scan.
