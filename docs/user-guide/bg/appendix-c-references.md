- statsmodels: `multipletests`, `method="fdr_bh"`. https://www.statsmodels.org/stable/
- R пакетът `fpc`, справочната страница на `clusterboot` (формулировките за стабилност). https://search.r-project.org/CRAN/refmans/fpc/html/clusterboot.html
