# Steam Success Study: User Guide

This guide is for researchers who read and use the study's results: the Top-N Datasets, the feature analysis and the Tag Network app. It assumes no training in network analysis. To install and run the pipeline itself, see the [Running Guide](../running-guide.md).

Domain terms (Tag, Cluster, Network State, …) are used as defined in the project glossary, [CONTEXT.md](../../CONTEXT.md).

In the Tag Network app, every metric, and every control whose effect needs interpretation, shows a short explanation on hover and opens its entry in this guide on click. Each entry the app opens begins with an **In short** block (what it is, which direction is which, why it matters here, the main caution) and has a *Why it matters here.* paragraph on its use in this study.
